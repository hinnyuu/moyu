# v0.0.1 发布说明

状态：已创建 `v0.0.1` 标签（提交 `aa6398e1`），由 `release` workflow 发布。

## 范围

- 交付 ZIP 打包：DOS mtime、媒体内部时间字段、manifest、原子写与校验。
- 服务：FastAPI API、worker、独立 preview、独立 tusd、Rust TLS gateway。
- Web：React SPA、批量上传、断点续传、视频 HLS、可选 WASM 客户端 ZIP。
- 运维：单镜像五容器 Podman pod、Quadlet、配置迁移/审计、GHCR 发布、SBOM/Trivy。
- 安全：bootstrap token、PBKDF2、签名会话 cookie、CSRF、登录速率限制、密码重置、多用户角色、网关管理 token。

## 验证矩阵

- `agent-gate`：提交记录、模块 history、文档链接。
- `python`：模块单测、进程级 E2E、API 重启续传、>4GiB ZIP64。
- `rust`：fmt/check/clippy/test/wasm target。
- `web`：typecheck、Vitest、Playwright mock E2E、WCAG AA（亮/暗）。
- `fullstack`：真实 api/worker + 构建后 Web 的 Playwright。
- `podman` / `podman-arm64`：单镜像五容器 smoke。
- `release`：GHCR、Syft SBOM、Trivy 报告。

## 已知限制

- WASM 支持 STORE ZIP、图片 PNG/JPEG 转码；Web 视频转码使用 ffmpeg.wasm，需 COOP/COEP，失败回退服务端。
- 发布镜像构建 amd64 + arm64 多架构 manifest；未实现镜像签名。
- 更多故障注入与长时间运行测试未接入。
