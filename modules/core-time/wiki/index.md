# core-time 模块（人类说明）

core-time 负责回答一个问题：既然最新文件应该在“现在”完成，那么其他文件应该显示几点？它只算时间，不碰文件。

core-time 负责回答一个问题：既然最新文件应该在“现在”完成，那么其他文件应该显示几点？它只算时间，不碰文件。

## 第一阶段实现

`moyu-core` 现在能计算一组文件的相对时间计划：最新的文件对齐目标时间，其他文件保持原有间隔，并转成 ZIP 使用的 DOS 时间。它不读文件、不写 ZIP、不查系统时区；时区偏移由调用方传入。
