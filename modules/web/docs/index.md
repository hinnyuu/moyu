# web 模块文档

状态：v0.0.1 架构草稿，尚未实现。

## 职责

React + Vite + TypeScript 静态 SPA：上传队列、任务、预览、配置、管理。

静态构建，无 SSR；同源 `/api`；TanStack Query/上传状态机；批量队列、断点续传、预览播放、配置表单、token 管理；WASM 可选懒加载。

## 非职责

不直接访问数据库/文件系统、不承担默认媒体处理。

## 依赖

contracts 生成的客户端

## 接口

HTTP API；可选 lazy WASM

## 主题与可访问性

- 必须支持 `system`、`light`、`dark` 三种主题模式。
- 默认跟随系统 `prefers-color-scheme`；用户可手动切换，选择持久化。
- 首屏加载前应用主题，避免亮色闪烁。
- 使用语义化 design tokens（背景、表面、文字、边框、状态色、焦点色），禁止在组件里散落硬编码颜色。
- 正文对比度至少达到 WCAG AA；焦点环、禁用态、错误态在两种主题下都必须清晰。
- 媒体预览不随主题反相；透明通道使用中性棋盘格；预览背景与界面主题分离。
- 暗色主题是 v0.0.1 的验收项，不是可选增强。

## 失败模式

上传中断、API 错误、预览格式不支持、WASM 能力不足。

## 测试

组件/状态机、typecheck、Playwright 上传/预览/配置；亮/暗两套主题的视觉回归、对比度检查、主题切换持久化、首屏无闪烁。

## 替换点

React 可替换为 Vue/Svelte；只依赖 OpenAPI。
