# storage 模块文档

状态：v0.0.1 架构草稿，尚未实现。

## 职责

上传暂存、资产、任务、输出、预览缓存、配额和清理。

本地文件系统适配器优先；数据根目录由配置决定；上传暂存、资产、任务工作区、输出、预览缓存分区；配额、TTL、孤儿清理；不直接暴露 HTTP。

## 非职责

不做 HTTP、不生成预览、不解析媒体格式。

## 依赖

contracts

## 接口

AssetStore、路径/配额/清理接口

## 失败模式

磁盘满、权限、路径逃逸、配额、孤儿文件。

## 测试

路径安全、配额、清理、并发写、重启恢复。

## 替换点

本地 FS → NAS/S3；通过同一接口。
