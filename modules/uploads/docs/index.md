# uploads 模块文档

状态：v0.0.1 架构草稿，尚未实现。

## 职责

tus 断点续传会话、偏移量、完成钩子、入库。

前端 tus-js-client；tusd 负责分片/偏移/断点；API 签发上传 token/批次；完成后校验并注册资产；会话 TTL、清理、最大文件大小、配额。

## 非职责

不解析媒体、不打包、不直接写数据库业务表。

## 依赖

contracts, storage

## 接口

UploadSessionStore；tusd 完成钩子

## 失败模式

偏移不匹配、断点恢复失败、会话过期、磁盘满、校验失败。

## 测试

断网/刷新/重启恢复、并发批量、配额、完成钩子、清理。

## 替换点

tusd → 自研/其他协议，保持会话与完成契约。
