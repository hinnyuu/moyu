# v0.0.1 架构草稿

## 背景

旧原型验证了时间平移、ZIP 打包、内部元数据改写和性能，但仓库结构、文档、版本和部署方式不适合长期 agent 维护。v0.0.1 将以架构、契约和模块边界重新组织，旧实现只作为测试素材和参考。

## 改动

- 建立 `docs/`、`history/`、`wiki/` 三棵独立文档树。
- 建立模块清单：contracts、core-time、media-metadata、archive-zip、pipeline、config、storage、uploads、preview、api、worker、web、wasm-client、gateway、deploy、agent-gate。
- 确定运行时：单镜像、单 Podman pod、多容器；gateway 可选；api/worker/preview/tusd 分离。
- 确定语言：Python 后端 + TypeScript Web + Rust gateway/WASM；不引入 Go。
- 确定 Rust workspace：一个 workspace、三个 crate（gateway、wasm-client、core-time/rust）。
- 确定配置：多文件、`/config` 持久目录、WebUI 管理运行配置、部署配置不由 WebUI 直接控制 Podman。
- 确定端口：不写死；host/bridge 均可；端口变更按模式重启或重建。
- 确定证书：mount 目录、轮询 + API、token 由 WebUI 管理、只读重载不接收上传。
- 建立根级 docs 与 wiki 草稿。

## 影响

- 本提交只有文档，没有业务实现。
- `main` 上的旧原型代码暂不删除；新架构实现将在后续提交中逐步替换。
- `v0.0.1` 标签尚未创建。

## 验证

- 文档结构人工检查。
- agent-gate 尚未实现；后续实现后需补充门禁校验。

- 阶段 1：core-time、media-metadata、archive-zip、pipeline。
